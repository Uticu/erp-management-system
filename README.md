# Orders & Inventory Management System

> A full-stack web application built to manage warehouse products, client data, and process orders efficiently.

## About The Project

This project simulates a real-world order management system. The backend is fully developed using a strict layered architecture, exposing a robust RESTful API. 
The frontend is currently under development, with the API integration layer and TypeScript typings already established.

## Tech Stack

**Backend (Fully Implemented):**
* **Java 17+** 
* **Spring Boot** (REST API)
* **Spring Data JPA / Hibernate** (ORM)
* **MySQL** (Relational Database)

**Frontend (Under Development):**
* **React** 
* **TypeScript** (Strict typing mapped to backend DTOs)
* **Vite** (Build Tool)
* **Tailwind CSS** (Styling)
* **Axios / Fetch** (API Integration)

## Architecture & Current Status

### Backend (100% Complete)
Built using a standard enterprise layered architecture:
* `controller/`: REST API endpoints.
* `service/`: Business logic and validation.
* `repository/`: Database access (Spring Data JPA).
* `model/` & `dto/`: Entities (`Client`, `Products`, `Orders`, `OrderDetails`, `Bill`) and Data Transfer Objects.
* `exception/`: Global error handling.

### Frontend (WIP)
The foundation of the frontend is set up focusing on type safety and modular API calls:
* `src/types/`: TypeScript interfaces mirroring the backend models.
* `src/lib/`: API communication services (`clientLib.ts`, `productLib.ts`, `ordersLib.ts`, `bill.ts`).

## Key Features

* **Client & Product Management:** Full CRUD operations for clients and warehouse inventory.
* **Order Processing:** Validates product stock before finalizing an order.
* **Automated Billing:** Generates an immutable `Bill` record for every successful order. *(PDF export feature is currently planned).*
* **Stock Updates:** Automatically decrements product quantities upon order completion.

## Getting Started

### Backend Setup
1. Create a MySQL database (e.g., `orders_db`).
2. Configure your `application.properties` with your MySQL credentials.
3. Run the Spring Boot application. The tables will be auto-generated by Hibernate.
4. The backend server will start on `http://localhost:8080`.

### Frontend Setup
1. Open a new terminal and navigate to the fronted directory:
   Bash
   cd frontend
2. Install dependencies:
   Bash
   npm install
3. Start the Vite development server:
   Bash
   npm run dev
4. Open your browser and go to http://localhost:5173
